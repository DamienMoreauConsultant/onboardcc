### 3.2 Nuance booléens : vide ≠ NON, vide = NULL

Pour les 5 colonnes booléennes concernées (`zone_orange`, `conditions_spartiates`,
`hopital_proche`, `deuxieme_poste_partenaire`, `deuxieme_poste_alentour`) : **avant** ce correctif,
vérifie comment une cellule vide est actuellement traitée à l'import. Si le code actuel convertit
une cellule vide en `false` (NON) plutôt qu'en `NULL`, corrige ce mapping — une cellule vide doit
donner `NULL` en base, jamais `false` par défaut. Une fois ces colonnes rendues **Mandatory** (§3.1),
une valeur `NULL` en résultant (cellule vide) doit être **rejetée à la validation** avec un message
explicite nommant la colonne et la ligne concernées — pas silencieusement acceptée comme `NULL` ni
convertie en `false`.

### 3.3 Correctif d'algorithme — Langue non requise (P4_22, précision de Claude)

⚠️ Ce point n'est **pas** qu'une question d'import — l'algorithme actuel ne gère pas le cas "le
poste ne demande aucune langue". Corrige `scoringLangue` (`services/matching.js`,
`prompt4.txt` §5) :

```js
// AVANT :
function scoringLangue(voeux, poste) {
  // suppose implicitement qu'une ligne langue_poste existe toujours
  if (candidatParleLangueRequise(voeux, poste)) {
    return memeNiveau ? 10 : 7;
  }
  return voeux.nouvelle_langue ? 5 : 0;
}

// APRÈS :
function scoringLangue(voeux, poste) {
  if (!poste.langue_requise) return 10;  // aucune langue exigée par le poste → non-critère, score maximal
  if (candidatParleLangueRequise(voeux, poste)) {
    return memeNiveau ? 10 : 7;
  }
  return voeux.nouvelle_langue ? 5 : 0;
}
```

Trace bien ce cas dans `criteres_detailles` (critère "Langue", valeur_poste = "Aucune langue
requise", note = 10) — pas une ligne absente, pour que le détail du scoring OD reste cohérent (6
critères toujours affichés dans la section Contexte, voir `prompt4b`).

**Recalcul en masse requis** après ce correctif, comme pour les précédents changements d'algo
(`prompt4c`) — une opportunité liée à un poste sans langue requise voit potentiellement sa
`note_contexte` changer.
